# Taskify

Taskify is a clean and modern To-Do List app built purely with HTML, CSS, and JavaScript. It helps you manage your tasks efficiently with a smooth and responsive interface.

# Features

✅ Add and delete tasks

✅ Filter tasks: All, Active, Completed

✅ Clear completed tasks

✅ Responsive design with attractive gradients
